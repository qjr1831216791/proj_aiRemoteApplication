**AC1 切组网 → 在线 → 外部成员可访问**

- AC 原文（spec §3）：*Given 组网配置就绪（网络名/密钥经脚本写入配置文件、成员设备已安装 EasyTier 客户端并加入同一网络）When 在工作台切换到组网通道并确认 Then easytier-core 启动、看板通道显示「组网/在线」，外部独立网络（非宿主机所在网络）的成员设备经 `https://ai.jackqi.cn/`（标准 443）可访问。*
- 步骤：
  1. 前置：密钥已写入（见 AC8 步骤）；成员手机已装 App 并以同网络名+密钥加入。
  2. 主界面「访问通道」卡选**组网** → 确认（两步确认含「直连将随之停用」提示）。
  3. UAC 弹窗（服务管理）→ 允许。
  4. 观察通道卡与组网状态区（约 1 分钟内）：服务拉起 → peers 出现成员项。
  5. 手机（蜂窝网络 + EasyTier 已连）浏览器开 `https://ai.jackqi.cn/` → 应正常加载。
- 预期：看板「组网/在线」，成员列表含手机（hostname/虚拟 IP/延迟/丢包实测值）；手机访问成功。**不采信宿主机本机浏览器探测**（004 口径）。

### US2 · 停用旧通道

**AC5 停用穿透（frp）**

- AC 原文：*Given 穿透（frp）在用或已配置 When 执行「停用穿透」Then frpc 停止且不再被守护/自启/启动链拉起；SakuraFrp 的 CNAME 记录经 DNSPod API 清理（失败回退手动指引）；`SAKURA_FRP_KEY` 清除指引呈现（脚本提供清除入口，凭证不进 APP）；看板显示「穿透/已停用」。*
- 步骤：
  1. 前置：当前通道为组网（穿透非现役才可停用——按钮在设置页「通道停用」卡）。
  2. 点「停用穿透」→ 确认框（安全警示）→ 确认（frpc 在跑会走 UAC 停止）。
  3. 验证四件事：
     a. `tasklist | findstr frpc` 无输出；
     b. DNSPod 控制台 `ai.jackqi.cn` 的 CNAME（frp-can.com）记录已**删除**（API 失败时界面应显示手动指引而非静默）；
     c. 界面呈现 `SAKURA_FRP_KEY` 清除指引 → 点入运行 `clear-frp-key.ps1` → 复核显示已移除，栈 `.env` 中该行消失（其余行保留）；

**AC10 换钥即吊销**

- AC 原文：*Given 密钥需要更换 When 重新执行密钥脚本 Then 新密钥写入并生效后，持旧密钥的成员设备无法再接入组网（换钥即全体吊销，成员需更新）。*
- 步骤：
  1. 前置：手机（旧密钥）在线、可访问。
  2. 重跑 `set-mesh-secret.ps1` 输入**新**密钥 → 设置页「应用」（或通道卡重切组网）→ UAC 重启服务。

  4. 手机 App 更新为新密钥 → 重连 → peer 表恢复、访问恢复。
- 预期：旧钥成员被吊销、新钥成员恢复——「换钥 = 全体吊销」语义成立。
