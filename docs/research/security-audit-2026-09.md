## 1. 威胁模型一句话

密钥（network_secret）只把守**组网边界**（谁能入 EasyTier 网）；边界之后 CloudCLI 零认证、明文 HTTP、自带 shell 终端，且以宿主机管理员用户运行（上游有未认证 RCE 前科 CVE-2026-31975，CVSS 9.8）。全链路：

```
成员浏览器 → https://域名 (443, caddy, 防火墙白名单: 源∈组网网段+TUN)
           → reverse_proxy 127.0.0.1:3001 → CloudCLI（零认证 + shell）
```

即「网内即完全信任」——任何绕过边界的路径都直达 shell，这是全部发现的共同放大器。

## 3. 本轮确认的强化方案（需求方 2026-09-13 拍板）

①③确认推进；②确认推进且**必须配套「傻瓜式组件升级脚本」**；低概率事件（依赖 0day、防火墙漂移）暂不考虑。

### P1 工作台命令面硬化

- **domain 注入**：dispatch 组装参数前对 `domain` 做 DNS 主机名形态校验（字符白名单 + 段格式 + 长度上限），拒绝即报错不执行；
- **SHA256 短路**：`prepare_stack` 在 exe 已存在时同样执行 `verify_easytier_binaries`（五文件校验为毫秒级哈希读取，不构成性能顾虑）；
- **CSP 基线**：`tauri.conf.json` 设 `default-src 'self'` + Tauri 2 所需的 ipc 源（具体指令集 plan 阶段定），挡住「注入即执行」的最后一环。

工作量：合计约一天，含单测（注入用例：`;`、`'`、空格、反引号等元字符全拒）。

### P2 Caddy 指纹锁定

- **方案 A（改下载）**：构建 URL 增加 `&version=<核心版本>`，脚本内置该版本 SHA256；下载后校验，不符拒绝安装并引导 `-CaddyZip` 手动兜底。**待验证风险**：caddyserver.com 按需构建的产物是否字节级可复现——若不可复现则转 B。
- **方案 B（随包内置）**：caddy.exe 与 EasyTier 五文件同待遇——随包分发 + 哈希锁 consts.rs，装机不再下载。附带收益：装机可离线、规避构建站下载慢/失败的既有痛点（`-CaddyZip` 兜底即为此而生）。代价：安装包体积 +≈40MB。
- 两案共同前置：URL 或内置文件必须与哈希**同源锁定**（版本号与哈希成对出现，升级时成对变更）。

### P3 443 入口账号密码（basic_auth）

- 位置：`install-https.ps1` 生成的 Caddyfile 增加 `basic_auth` 段——全链路唯一咽喉，一处生效；
- 凭证：bcrypt 哈希写栈目录 `.env`、Caddyfile 以 `{$...}` 引用不落明文（复用 ADR-0003 腾讯云密钥的密钥工程模式）；
- 入口：设置区或装机向导加「设置访问密码」步骤（形态同 set-mesh-secret.ps1）；
- 边界说明：局域网例外开关打开的 12h 内流量直连 3001 不经 caddy，密码不挡——例外本身是显式信任动作，操作提示已覆盖；
- 历史注记：2026-09-12 spec010 方案评审曾否决 basic_auth——彼时它是「局域网收口手段」候选（不满足网络层不可达性质）；本轮定位是「组网内纵深防御」，场景不同，不构成推翻。

## 4. 傻瓜式组件升级脚本设计（P2 配套，需求方 2026-09-13 要求）

目标：一条命令完成组件升级，版本号、哈希、内置二进制、测试全部联动，人只负责看结果。

```
tools/upgrade-component.ps1 -Component caddy|easytier -Version x.y.z [-PluginVersion a.b.c]
```

流程（幂等，每步可独立重跑）：

1. **读 manifest**：各组件的下载 URL 模板、锁定值位置（install-https.ps1 / consts.rs）、目标文件清单；
2. **下载**（可选镜像）→ 预检（大小 + MZ 头）→ 计算 SHA256；
3. **自动改写**：caddy → install-https.ps1 的版本与哈希常量；easytier → consts.rs 五哈希 + 新二进制复制入 resources；
4. **自动验证**：`cargo test`（哈希相关过滤）+ 改后脚本语法检查；
5. **输出变更摘要**：新旧版本/哈希对照 + 改动文件清单，提示提交（关联 Spec 编号）与发版。

归属：纯仓库侧开发工具，不随安装包分发，落 `tools/`（与 `scripts/` 生命周期命令的职责分离一致）。
